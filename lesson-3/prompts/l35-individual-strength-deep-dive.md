PROMPT FOR DEEP TACTICAL ACTIVATION
You are creating a comprehensive tactical guide for someone who has identified [STRENGTH NAME] as one of their core dormant capacities. This person has been using this strength unconsciously and haphazardly. Your job is to help them develop systematic mastery.
Generate a detailed tactical guide that includes:
PART 1: DEMYSTIFYING THE STRENGTH
* Explain what this strength actually means in plain language
*  Break down the difference between unconscious and conscious use
*  Provide 5 specific examples of this strength in action
*  Address common misconceptions about this strength
*  Explain why this strength matters more now than ever
PART 2: RECOGNITION & ASSESSMENT
Create a self-assessment framework:
* 10 questions to identify current unconscious use
*  Scoring system to measure current capability
*  Examples of beginner/intermediate/advanced expressions
*  Common blocking patterns that suppress this strength
*  Personal archaeology process to find past evidence
PART 3: DAILY PRACTICE ARCHITECTURE
Design specific, time-bound practices:
5-Minute Morning Activation:
* Exact steps
*  What to track
*  Expected sensations/outcomes
*  Troubleshooting guide
20-Minute Deep Practice (3x/week):
* Session structure
*  Skills being developed
*  Progress markers
*  Common mistakes to avoid
Weekly Integration Session (1 hour):
* Review framework
*  Synthesis process
*  Planning next level
*  Accountability metrics
PART 4: PRACTICAL APPLICATION FRAMEWORKS
Provide 3-5 specific frameworks/models including:
* Framework name and purpose
*  Step-by-step usage instructions
*  Real-world example walkthrough
*  Template/worksheet design
*  When to use vs. when not to use
*  How to teach this framework to others
PART 5: MONETIZATION PATHWAYS
Detail 3 ways to monetize this strength:
Immediate (within 30 days):
* Specific offer structure
*  Pricing rationale
*  Sales conversation framework
*  Delivery template
*  Success metrics

* Scalable product design

*  Systematic delivery
Advanced (6-12 months):
* Premium positioning

*  Enterprise applications
*  Speaking/thought leadership
*  Creating new categories
PART 6: TOOLS & TECHNOLOGY STACK
Specify exact tools needed:
* Free tools to start
*  Paid tools for scaling
*  How to build custom tools
*  Templates and frameworks
*  Tracking and measurement systems
*  Integration with existing workflows

* Observable behaviors
