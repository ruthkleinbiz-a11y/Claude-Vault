## CDT Frameworks Included

Based on the consumed source material, the chart covers these 8 established developmental frameworks:

| Framework | Description | Source Field |
|-----------|-------------|--------------|
| **Robert Kegan's Subject-Object Theory** | 5 orders of consciousness — what you can see vs. what you ARE | Developmental psychology |
| **Spiral Dynamics** | Value memes / levels of existence — worldview evolution | Cultural development theory |
| **Ego Development Theory** | Loevinger/Cook-Greuter stages — self-identity complexity | Personality psychology |
| **Moral Development** | Kohlberg stages — ethical reasoning sophistication | Developmental psychology |
| **Faith Development** | Fowler stages — meaning-making and transcendence | Religious studies / psychology |
| **Cognitive Development** | Piaget / post-formal operations — thinking complexity | Cognitive psychology |
| **Self-Determination Theory** | Deci & Ryan — autonomy, competence, relatedness | Motivation theory |
| **Maslow's Hierarchy** | Needs levels — physiological to self-actualization | Humanistic psychology |

## Chart Structure (4 Columns)

When Claude personalizes this chart in Step 6, it adds 4 columns to each framework:

### Column 1: User's Current Ranking
Where the user falls within this framework based on ALL accumulated data (Calibration 1 + 2, Subject-Object Fractal, reflections). Must cite specific evidence.

### Column 2: Reason for Ranking
Why this ranking? References to specific answers, patterns, or behaviors demonstrated. No vague reasoning.

### Column 3: Next Level
What the next developmental stage looks like in this framework. Described concretely — what would the user think, feel, and do differently?

### Column 4: What to Do to Get There
Specific actions, experiments, or mindset shifts. Not generic advice. References the user's actual life circumstances.
