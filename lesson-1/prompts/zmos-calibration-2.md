### What changes for Claude:

1. **Day 8 → Step 4 of Lesson 1** — The original labels this "Day 8" (implying Days 1-7 of Calibration 1 are complete). In the Claudified SOP, this runs as Step 4, immediately after Step 3 (Calibration 1). The user can take a break between them, but it's the same lesson.

2. **"Summarize Day 7 insights"** → Claude reads `outputs/calibration-1-responses.md` and `outputs/psych-profile.md` to summarize what it learned in Calibration 1. Asks the user to confirm or correct before proceeding.

3. **Dynamic follow-ups** — The original generates 1-2 follow-up questions after each core question. This is a key feature — Claude should generate probing follow-ups that go deeper than the multiple-choice options allow.

4. **Fear-focused questions** — All 20 questions target fear, threat perception, risk avoidance, and vulnerability. This is the emotional depth layer that Calibration 1 (aspirations/identity) doesn't reach.

5. **Updated personality predictions** — By Step 4, Claude has 50 data points (30 from Cal-1 + 20 from Cal-2 + follow-ups). Predictions should become more confident. Show the delta: "Your Enneagram prediction moved from Type 5: 65% to Type 5: 82% based on your fear responses."

6. **Score should approach 80+** — After both calibrations, the Zenith Mirror Score will typically land in the 60-80 range. A score of 60-80 at this point is normal — the Prediction Improvement Protocol (described in the instructions section below) is specifically designed to raise it to 80+ before the user proceeds to Mirror Prompt 1. If the score is still below 60, something is wrong — the user may be giving surface-level answers. Do NOT proceed to Mirror Prompt 1 with a score below 80; run the Prediction Improvement Protocol first.
