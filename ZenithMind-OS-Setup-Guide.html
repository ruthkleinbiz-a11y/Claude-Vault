What Is ZenithMind OS?

ZenithMind OS is a 4-lesson personal development system that uses AI to build the most detailed psychological profile you've ever had — then uses that profile to help you see your blind spots, overcome self-sabotage, and execute on what matters most.

It works with Claude — Anthropic's AI. You talk to Claude naturally, and it guides you through everything: personality assessments, fear mapping, growth stage analysis, blind spot reports, and more. All your data saves automatically so you can pick up anytime.

What you'll need: A computer with internet, an email address, and a willingness to be deeply honest about yourself. That's it.

Total time: Lesson 1 takes 5–8 hours (can be done in a day or spread across a week). Lessons 2–4 unfold over weeks as you implement what you learn.

Choosing Your Path: App or Code

Both paths run the full ZenithMind OS course. Both give you the same AI mirror, the same deep profile, the same calibration experience. The difference is what happens after.

The Claude App is the conversational path. You open Claude in your browser, the AI guides you through each lesson, and you build your profile through dialogue. It works. It's familiar. If you've used ChatGPT or Claude before, you'll feel at home immediately.

Claude Code is the builder's path. Same conversation — you talk, Claude talks back. But Code also reads and writes files, generates PDF reports, and runs multi-phase skill sequences that produce deployment-ready business tools from your profile data.

Here's what that means in practice: the ZenithMind upgrade skills — the ones that turn your profile into prospect assessments, positioning architecture, 30-day content plans, and client psychology maps — only run in Code. They need to read your Scorecard, write analysis files, and generate branded PDFs. The app can't do any of that.

"But I'm not technical"

Most ZenithMind users aren't. The coaches, consultants, and experts in this program chose Code and none of them had a terminal on their screen before this.

Here's the truth: Claude Code looks more intimidating than it is. It's a dark screen with text instead of a chat window. That's the entire difference. You still type in plain English. Claude still responds in plain English. The setup takes about 10 minutes, and this guide walks you through every step.

Once you're in, you forget you're in a terminal. You're just talking to Claude — except now Claude can actually build things for you.

Our recommendation

If you want the full ZenithMind experience — especially the upgrade skills that turn your profile into business tools you can deploy Monday morning — start with Code. The few extra minutes of setup unlock a fundamentally different level of capability.

If Code feels like too much right now, start with the app. You can always switch later — your profile data transfers. But the people who started with Code? They'll tell you the same thing: "I wish I hadn't hesitated."

Section 1: Setup with Claude App

The fastest way to start. Download the app, sign in, and go.

Step 1: Get Claude

  1. Go to claude.ai — click "Get Started" or "Sign Up"
  2. Create an account with your email — or sign in with Google
  3. Choose a plan: Claude Pro ($20/month) gives you enough usage. Free tier may hit limits.
  4. Optional: Download the desktop app from claude.ai/download. Web version works fine too.

Step 2: Set Up Your ZenithMind Project

  1. In Claude, click "Projects" in the sidebar (or create a new Project)
  2. Name it: ZenithMind OS
  3. Upload the ZenithMind OS folder contents to the project:
    • Upload the CLAUDE.md file from the root of the ZenithMind folder
    • Upload all files from the lesson-1/ folder (CLAUDE.md + all prompt files)
  4. Start a new conversation in the project

Step 3: Start ZenithMind

Type: "Let's start ZenithMind"

Claude will read the instructions, introduce itself, and guide you through Lesson 1. Just answer honestly and follow Claude's lead. It handles the questions, scoring, file saves, and transitions.

Note for App users: When you finish Lesson 1 and move to Lesson 2, you'll need to upload the Lesson 2 files to your project. Claude will tell you when it's time. With Claude Code, this happens automatically.

Section 2: Setup with Claude Code (Recommended)

More powerful. Claude reads and writes files directly on your computer. Your profile data lives in visible files you can browse anytime.

Step 1: Install Node.js

  1. Go to nodejs.org — download the LTS version (the big green button)
  2. Run the installer — accept all defaults

Step 2: Install Claude Code

  1. Open Terminal (Mac: search "Terminal" in Spotlight) or Command Prompt (Windows: search "cmd")
  2. Type: npm install -g @anthropic-ai/claude-code and press Enter
  3. Wait for it to finish installing

Step 3: Create Your Claude Account

  1. Go to claude.ai and create an account (if you don't have one)
  2. Choose Claude Pro ($20/month) or Claude Max for heavier usage
  3. When you first run Claude Code, it will ask you to sign in — just follow the prompts

Step 4: Install Obsidian (Optional but Recommended)

  1. Go to obsidian.md and download the free app
  2. Open Obsidian, create a new vault, and point it at your ZenithMind-OS folder
  3. This lets you browse all your profile data, outputs, and progress in a clean interface

Step 5: Start ZenithMind

  1. Unzip the ZenithMind-OS folder to wherever you want on your computer
  2. In Terminal, navigate to that folder: cd path/to/ZenithMind-OS
  3. Type: claude and press Enter
  4. Say: "Let's start ZenithMind"

Claude reads the instructions automatically and guides you through the entire program. It handles questions, scoring, file saves, and lesson transitions. Just answer honestly.

Why Code is worth the 10 minutes: No file uploading between lessons. No copy-pasting prompts. Claude reads your files directly, saves your outputs automatically, and transitions between lessons without you lifting a finger. Your entire psychological profile lives in files you own and can see. And when you're ready for the upgrade skills — the ones that build branded PDFs, prospect assessments, and 30-day content plans from your data — they're already there waiting.
