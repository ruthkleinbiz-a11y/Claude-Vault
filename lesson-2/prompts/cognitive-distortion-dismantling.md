## What It Does

Systematic deconstruction of cognitive distortion patterns using principles from Cognitive Behavioral Therapy (CBT) but going significantly deeper — not just identifying distortions, but dismantling the neural circuits that maintain them and engineering replacement thought architectures.

The Orchestrator often sequences this protocol when "catastrophizing patterns" are identified in the Observer output (example from Rich's Lesson 2 Transcript: "Day 7: Your catastrophizing patterns need work → Run Cognitive Distortion Dismantling").

## Prerequisites (from source)
- Requires BOTH Mirror Prompt output AND Omniscient Observer output
- Minimum 5,000 words output specified (smallest of the 5 new protocols)

First, systematically analyze all Mirror Prompt and Omniscient Observer outputs, extracting and categorizing EVERY cognitive distortion pattern present. You MUST identify patterns the user themselves cannot see.
PHASE 1: DISTORTION CONSTELLATION MAPPING (800 words)
Map the complete cognitive distortion ecosystem operating in the user's psychology. This is NOT a simple list - you must:
* Expose the interconnected web of distortions, showing how each reinforces others
* Reveal the developmental origin of each distortion pattern
* Identify the hidden payoffs and secondary gains from maintaining each distortion
* Demonstrate how these distortions form a self-reinforcing system that resists change

For each core distortion, perform a 5-level deep interrogation using the recursive questioning matrix:
1. Initial Pattern: "What is the visible thought pattern?"
2. Hidden Assumption: "What must be believed for this pattern to exist?"
3. Core Belief: "What fundamental belief about self/world enables this assumption?"
4. Origin Story: "What formative experiences installed this belief?"
5. Maintenance Mechanism: "What current behaviors/thoughts maintain this belief despite evidence?"
For EACH distortion, you must reach level 5. No exceptions.
PHASE 3: NEURAL CIRCUIT DISRUPTION FRAMEWORK (800 words)
For the three most damaging cognitive distortions, create precise pattern interruption protocols that:
* Identify the exact trigger moment when the circuit activates
* Prescribe a specific pattern-breaking response that creates cognitive dissonance
* Design a replacement thought loop that must be rehearsed immediately after interruption
* Create a 7-day neural recoding sequence with daily specific challenges
* Include physiological anchoring techniques to cement new patterns
PHASE 4: REALITY TESTING MATRIX (700 words)
Create a comprehensive framework for systematically challenging each distortion through:
* Counterfactual evidence collection methodology (minimum 3 evidence types per distortion)
* Perspective-shifting exercises that force cognitive flexibility
* Probabilistic recalibration techniques for catastrophic thinking
* Temporal expansion methods for challenging permanence distortions
* Identity-level questioning for dismantling core self-limiting beliefs
PHASE 5: DISTORTION REVERSAL ENGINEERING (900 words)
For each major distortion category, reverse-engineer a diametrically opposed thought architecture that:
* Operates from an entirely different set of core assumptions
* Generates automatic interpretations that empower rather than limit
* Creates confirmation bias toward opportunity and possibility
* Establishes evidence-filtering mechanisms that prioritize capability over limitation
* Produces emotional states conducive to expansion rather than contraction
PHASE 6: INTEGRATION BLUEPRINT (800 words)
Create a precise implementation framework that:
* Sequences distortion dismantling in optimal order for minimal resistance
* Establishes clear metrics for recognizing successful pattern dissolution
* Provides specific exercises for moments of highest pattern vulnerability
* Creates daily reinforcement rituals for new cognitive frameworks
* Designs environmental modifications that reduce distortion triggers
PHASE 7: RECURSIVE DEEPENING (700 words)
Return to the entire analysis and:
* Identify meta-patterns operating across all distortions
* Expose any analytical blind spots in the previous phases
* Reveal how resistance to this process itself reflects core distortions
* Predict exactly how and when the user will attempt to reject these insights
* Create preemptive responses to each predicted resistance point
Remember: You are not providing generic CBT guidance. You are performing deep psychological architecture dismantling and reconstruction at a level that creates profound discomfort before breakthrough. Do not soften language or insights to be palatable. Truth is the only metric of success.

- Counterfactual evidence: Claude identifies specific instances from the user's own profile where evidence contradicts the distortion
