Path A: Code Tab

GETTING STARTED — TAKES ABOUT 5 MINUTES

If you completed zenithhub.ai, you already have the Claude app, Obsidian, and the integration set up. This is just the ZenithMind-specific part — download your folder and start. (On zenithhub.ai, make sure you selected ZenithMind OS from "Choose Your Program" at the top.)

1

Download the ZenithMind zip — Go to zenithpro.io, find the ZenithMind OS 2026 card, and click the Code download button. A file named ZenithMind-OS-Code.zip downloads to your computer. Don't unzip it — Claude will handle that for you.

2

Open Claude Code and tell it where your zip is — If you set up the Obsidian plugin from zenithhub.ai Part 4 (Rich recommends this), open Obsidian and launch a Claude Code terminal panel. Otherwise, open the Claude app and click the Code tab. Either way, tell Claude:

"I downloaded ZenithMind OS and the zip is in my Downloads. Set it up and let's start."

Claude finds the zip, extracts it, runs setup, and starts Module 1. That's it.

You should see: Claude greeting you and asking its first question. If you see this, setup is complete. Everything from here is just having a conversation.

How It Works

Your folder is Claude's memory. Everything saves automatically. Claude reads your files each session so it always knows where you left off. To resume, say "Let's continue ZenithMind." Lesson transitions are automatic.

Purchased ZenithMind Plus or Elite? Start with the OS setup above — that's your foundation. Plus includes professional positioning tools, Elite includes a complete AI-powered business system. Both run on the profile you build here.

Elite includes everything in Plus.

Download your upgrade from zenithpro.io. Claude will walk you through everything when you're ready.

Path B: Cowork Tab

Page 3

Cowork works — but it's limited. No file visibility, no Obsidian integration, no Plus or Elite skills. When you're ready, moving to Code (Path A) gives you the full experience — and Claude brings all your Cowork progress over automatically. Nothing restarts, nothing is lost. If you can, just start with Code.

Follow these steps in order — takes about 5 minutes
1

Download the Claude app — Go to claude.ai/download and install it. Mac: drag to Applications. Windows: double-click and install.

2

Sign in or create an account — Open the app. Already have a Claude account? Click "Sign In." New? Click "Sign Up", enter your email, create a password (write it down), and verify your email. Then subscribe to Pro ($20/month) via the "Upgrade" button.

3

Download your ZenithMind folder — Go to zenithpro.io, find the ZenithMind OS 2026 card, click Cowork download. Unzip it (Mac: double-click the .zip; Windows: right-click → Extract All) and drag the ZenithMind-OS-Cowork folder to your Desktop.

4

Open your folder in Claude — Click the Cowork tab at the top. Look for "Work in a Folder" and check it. Select ZenithMind-OS-Cowork from your Desktop. When Claude asks for permission, click "Always Allow."

5

Type "Let's start" and press Enter — Claude reads your folder, recognizes ZenithMind OS, and begins guiding you through Module 1. You're in.

You should see: Claude greeting you and asking its first question. If you see this, setup is complete.

How It Works

Your folder is Claude's memory. Everything saves automatically. Claude reads your files at the start of each session so it always knows where you left off. Your data lives on your computer, not in the cloud.

To pick up where you left off: Open the Claude app → Cowork tab → select your folder → type "Let's continue." Taking a break? Just close the app — everything is saved, Claude knows exactly where you are.

Purchased ZenithMind Plus or Elite? Complete the base program here, then switch to Code (Path A) — Plus and Elite skills require it. Download the Code version from zenithpro.io and follow Page 2. Setup detects your Cowork progress and brings everything over automatically.

Need help? Visit zenithpro.io for support and troubleshooting.
